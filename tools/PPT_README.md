TechnologyAgent PPTX generator

This folder contains `make_ppt.py` which generates `TechnologyAgent_Showcase.pptx` and two diagram PNGs:

- system_architecture.png
- ingestion_flow.png

Requirements

- Python 3.8+
- Virtualenv (recommended)
- Install dependencies:

```bash
python -m pip install python-pptx Pillow
```

Run

```bash
python tools/make_ppt.py
```

The script will create `TechnologyAgent_Showcase.pptx` in the repo root.
